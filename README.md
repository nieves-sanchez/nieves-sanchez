## Sobre mí

Soy Data Analyst con perfil técnico y una base importante en operaciones y negocio. Trabajo todo el ciclo del dato: desde la extracción y transformación hasta el análisis y la presentación de resultados a perfiles no técnicos.

Antes de especializarme en datos trabajé en entornos de calidad, operaciones y métricas. Eso me ayuda a entender qué pregunta tiene sentido hacerle a los datos y cuál no, algo que no siempre viene dado por el dominio técnico.

En cuanto a herramientas, trabajo principalmente con **Python y SQL** para ETL, análisis y modelado relacional, y con **Power BI** para visualización y reporting. Además, integro herramientas de IA —asistentes de código, LLMs— en el flujo de trabajo diario: para generar y revisar queries, documentar procesos, explorar datasets más rápido o automatizar partes repetitivas. Lo uso como una capa más de eficiencia, no como atajo para no pensar.

---

## En qué trabajo habitualmente

- ⚙️ Pipelines ETL en Python, limpios y reproducibles
- 🗄️ Modelado relacional de bases de datos (MySQL, normalización 3FN)
- 📊 Análisis exploratorio estructurado (EDA) orientado a tomar decisiones
- 🌐 Extracción de datos desde APIs y web scraping (BeautifulSoup, Selenium)
- 📈 Dashboards y reporting en Power BI
- 🤖 Integración de IA en procesos de análisis y automatización

## Proyectos

### 📊 HR Attrition — End-to-End Analytics
Pipeline ETL completo en Python, modelado relacional en MySQL (3FN) y análisis exploratorio para identificar los factores asociados a la rotación de empleados. Proyecto end-to-end desde los datos en bruto hasta los insights finales.
🔗 [Ver proyecto](https://github.com/nieves-sanchez/hr-attrition-end-to-end-analytics)

---

### 🧠 Mental Health in Tech — Data Analysis & Power BI
Análisis sobre salud mental en entornos tecnológicos: limpieza y EDA en Python, dashboard en Power BI. El objetivo era comunicar los resultados de forma clara para perfiles que no trabajan con datos directamente.
🔗 [Ver proyecto](https://github.com/nieves-sanchez/mental-health-tech-powerbi-analysis)

---

### 🎵 Music Trends — API Data & SQL Analysis
Extracción de datos desde la API de Last.fm, procesamiento con Python y análisis en SQL para identificar tendencias de consumo musical.
🔗 [Ver proyecto](https://github.com/nieves-sanchez/musicstream-listening-trends-analysis)
